# ARCHYNDIUM Browser 0.2.0

GitHub の Releases に下書きができたら、この内容を説明欄に貼り付けて「Publish release」を押します。

## 新しくなったところ

- **タブを上に並べる画面に**：一般的なブラウザと同じ形になりました。Work / Focus・ブックマーク・履歴などは、アドレスバー左のパネルボタンで開きます。以前の形（サイドバー）にも設定で戻せます。
- **新しいタブのスタートページ**：再生中の曲と今の歌詞、音楽に合わせて流れる色の波。検索エンジンもここから切り替えられます。
- **歌詞を 1 行表示**：アドレスバーの下に、再生中の曲の今の歌詞を 1 行だけ出せます。
- **季節の演出**：タブバーに雪・桜・雨・落ち葉が積もります。タブを動かすと落ちます（設定 → 演出で調整・オフ）。
- **テーマ**：白い標準テーマ、OS に合わせるテーマ、落ち着いた明るいテーマ 3 種類を追加。見分けにくかったテーマを整理しました。
- **検索エンジンの切り替え**：アドレスバーの左のアイコンから。シークレットタブ用の検索エンジン（初期値 DuckDuckGo）も選べます。
- **ページ翻訳・動画の字幕翻訳**：英語 ⇔ 日本語。Firefox と同じ翻訳エンジン（Bergamot）で、この PC の中だけで翻訳します（無料・回数制限なし・文章を外部に送らない）。翻訳モデルは初めて使う時にダウンロードします。字幕は原文と訳を並べて表示できます。
- **プレビュー**：タブ・リンクにマウスを乗せると内容を表示。
- **コピーできないページ**：コピー制限の解除と、ページの文字の取り出し。
- **ブックマーク**：右クリックから追加・編集・フォルダへの移動。小窓を作り直しました。
- **ウィンドウ**：タブを引き出した瞬間に新しいウィンドウに。別のウィンドウのタブバーに重ねて離すとそこに入ります（再生中の動画・音楽は同じ位置から続きを再生）。ウィンドウをまとめる。
- **細いウィンドウ**：入りきらないボタンは「»」にまとまり、タブはアイコンだけになります。
- **再生中の曲のボタン**：ほかのボタンと同じ大きさで固定。音楽が流れてもボタンの位置が動きません。曲が変わると歌詞を自動で表示（設定でオフ）。
- **読み込み中の表示**：通信が遅い時も、白い画面ではなく「読み込んでいます」と読み込みバーを表示。リロードボタンは読み込み中「中止」に。
- **閉じる時**：最後のウィンドウを閉じる時、タブが複数あれば確認。最後のタブを閉じるとウィンドウを閉じます。
- **新しいタブ**：開くとアドレスバーにすぐ入力できます。
- **ミニプレイヤー**：ガラス表示、大きさの変更（文字も大きく）、音量をサイトと同期。
- **広告ブロック**：標準 / 簡易 / オフ。動画・音楽サイトでは自動で簡易に。
- **サイトのデータの削除**：Cookie などをサイトごと・すべて削除。

## 直した不具合

- 調べていない言葉が検索エンジンの「最近の検索」に出ることがあった（入力中の URL を送らない・Cookie なしで候補を取得）
- 音楽を流していたタブを閉じても、プレイヤーに曲の情報が残っていた
- ウィンドウの空いた所が掴めないことがあった、最大化中に掴んで動かせなかった
- 動作が重くなる原因（全ページでの頻繁な処理など）を減らした
- YouTube の再生中に画面全体が暗くなることがあった（広告ブロッカー警告の幕が残っていた）
- ニコニコ動画の動画広告をスキップできなかった
- タブを増やすとウィンドウの ー □ × が押し出されて見えなくなった
- タブをすべて閉じて起動し直すと Development グループが復活していた
- マウスのサイドボタンで戻る・進むができないことがあった

## インストール

- 下の `ARCHYNDIUM-Browser-Setup-0.2.0.exe` をダウンロードして実行します。インストール済みの方は自動で更新されます。
- インストーラーにはまだコード署名がないため、Windows SmartScreen の警告が出た場合は「詳細情報」→「実行」を押してください。

## What's new (English)

- Tabs along the top like other browsers (sidebar layout still available in Settings)
- New tab start page with the playing song, its current lyric line and waves that move with the music
- Optional current lyric line under the address bar
- Seasonal effects on the tab bar (snow, petals, rain, leaves)
- Plain light theme, system theme and three calm light themes
- Switch search engines from the address bar; separate engine for private tabs
- On-device page and subtitle translation (English ⇔ Japanese) with the same engine as Firefox; bilingual subtitles
- Tab and link previews; unlock copy-protected pages and extract text
- Bookmarks from right-click menus; redesigned bookmark popup
- Tabs become a window the moment you pull them out, and join another window's tab bar when dropped on it; playing media continues from the same position
- Narrow windows: extra toolbar buttons move into a » menu and tabs shrink to icons
- Closing the last window with several tabs asks first; closing the last tab closes the window
- Mini player glass mode, resizing with larger text, volume synced with the site
- Ad blocking modes Standard / Light / Off, automatically Light on video and music sites
- Clear cookies and site data per site or for all sites
- Fixed now-playing button position, loading indicator for slow connections, auto lyrics on song change
- Fixes: search suggestions, now-playing info after closing a tab, window dragging, YouTube dark overlay, Niconico video ads, window buttons hidden by many tabs, mouse side buttons, performance
